# 验证说明

已在 macOS 26、Apple Silicon 与 Xcode 命令行环境构建运行。应用最低部署目标为 macOS 14，其他系统版本仍需实际验证，不能把部署目标当作测试覆盖。

验证项目：

- Release 构建通过；内置 `--self-test` 检查常见多行说明、嵌套元数据隔离、中文展示与原始调用名分离、WorkBuddy分组、760点宽布局。
- `--catalog-json` 对真实本地目录扫描，四类来源均有数据，当前扫描到的技能展示名称不含英文字母，没有未翻译回退项。
- 原始技能文件只读，中文显示映射保存在应用源码中。
- 从运行应用的原生视图导出预览，未以网页伪造软件界面。
- 原版应用文件保留，新版使用独立应用标识。首次使用应退出旧版，避免快捷键冲突与双图标。

未验证或不支持：模型执行结果、技能是否已被宿主启用、各宿主全部插件发现规则、非Codex调用次数、账号额度与云同步。未知项不伪填为0。
